# Design Tokens

Token reference for **Connect & Share**. Use utility classes and CSS variables — never raw values.

## Colors

Apply with any color utility: `bg-<name>`, `text-<name>`, `border-<name>`, `ring-<name>`, `divide-<name>`, etc.

| Name | CSS variable |
|---|---|
| `bone` | `--bone` |
| `bone-soft` | `--bone-soft` |
| `bone-deep` | `--bone-deep` |
| `ink` | `--ink` |
| `ink-soft` | `--ink-soft` |
| `clay` | `--clay` |
| `clay-deep` | `--clay-deep` |
| `teal` | `--teal` |
| `teal-deep` | `--teal-deep` |
| `amber` | `--amber` |
| `card` | `--card` |
| `popover` | `--popover` |
| `destructive` | `--destructive` |
| `border` | `--border` |
| `input` | `--input` |
| `sidebar-border` | `--sidebar-border` |
